# README artwork

The hero is an original procedural Blender/Cycles reconstruction of the reviewed SeeON device concept. It is newly rendered artwork, not a recovered original, product screenshot, actual hardware photograph, or evidence of production readiness.

Geometry, procedural materials, studio lighting, and cameras were created in Blender 4.3.2 and rendered with Cycles. Typography was composited with Pillow using installed Liberation Sans and Noto Sans CJK fonts. No image-generation model, downloaded model, stock photograph, or external image texture was used.

The master is 1800 × 1170 pixels; the README uses an optimized WebP. It contains no camera feed, resident data, customer records, or credentials.
